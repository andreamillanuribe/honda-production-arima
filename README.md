# ARIMA Modelling of Honda Car Production in Japan

## Project Overview
The objective was to analyse monthly Honda car production in Japan from 2013 to 2023 using time series analysis and ARIMA modelling.

## Project Objectives
- Analyse historical monthly production data.
- Transform the original time series to achieve stationarity.
- Identify and estimate an appropriate ARIMA model.
- Evaluate model performance through residual analysis and statistical tests.
- Analyse outliers and calendar effects, including the Trading Day Effect.
- Generate production forecasts for 2024.

## Methodology
- Time Series Analysis
- Stationarity and Unit Root Tests
- ACF and PACF Analysis
- ARIMA Model Estimation
- Residual Diagnostics
- Outlier Detection and Intervention Analysis
- Forecasting

## Tools & Technologies
- OxMetrics
- Econometric Analysis
- Statistical Modelling
- Time Series Forecasting

## Key Skills
Statistical Analysis, Data Analysis, Data Interpretation, Econometric Modelling and Forecasting.
